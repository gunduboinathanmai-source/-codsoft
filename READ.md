# Tic Tac Toe AI

This is a simple AI-based Tic Tac Toe game developed using Python.

## Features

- Human vs Computer gameplay
- AI-based smart moves
- Minimax Algorithm
- Winner detection
- Draw detection
- User-friendly interface

## Technologies Used

- Python

## How To Run

1. Open the project in Pydroid 3 or any Python IDE
2. Run the Python file
3. Enter positions from 1 to 9
4. Play against the AI

## Board Positions

1 | 2 | 3  
4 | 5 | 6  
7 | 8 | 9
