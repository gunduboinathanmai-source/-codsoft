🎬 Movie Recommendation System
🚀 Project Overview

This is a simple Movie Recommendation System built using Python.
It suggests movies to users based on their favorite movie’s genre.

The system uses basic logic (rule-based filtering) instead of complex machine learning.

🎯 Objective

To recommend similar movies to the user based on genre matching.

⚙️ How It Works
User Input → Find Movie Genre → Match Same Genre Movies → Show Recommendations
🧠 Logic Used
Store movies with Genre + Year
Take user favorite movie as input
Extract its genre
Compare with other movies
Recommend same genre movies
💻 Technologies Used
Python 🐍
Dictionaries (Data Structure)
Loops & Conditions
Basic Logic Building
