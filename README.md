# 🤖 AI Rule-Based Chatbot

A simple and interactive chatbot developed using Python that responds to user inputs through predefined conversational rules and basic AI logic.

## ✨ Features
- Responds to greetings and common questions
- Interactive text-based conversation
- Beginner-friendly AI project
- Exit option using "bye"

## 🛠️ Technologies Used
- Python
- Conditional Statements
- Basic NLP Concepts

## ▶️ How to Run

python chatbot.py

## 📚 Project Objective
To build a simple AI chatbot capable of interacting with users using predefined responses and logical decision-making.
