TASK-4 🎬 Movie Recommendation System 🚀 Project Overview

This is a simple Movie Recommendation System built using Python. It suggests movies to users based on their favorite movie’s genre.

The system uses basic logic (rule-based filtering) instead of complex machine learning.

🎯 Objective

To recommend similar movies to the user based on genre matching.
